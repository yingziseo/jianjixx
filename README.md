# CYRIL 产品视频云剪辑

用 GitHub Actions 在云端剪辑 CYRIL 头盔产品视频：每款 1 条 **30 秒、9:16 竖版、网页版（约 9MB）**，第一帧就是封面，并单独输出一张封面图。

- 素材：渲染时从飞书“赛罗素材库”（公开表格）按需下载，**用完即弃，仓库里不存素材**
- 成片：在 Actions 运行页面底部的 **Artifacts** 下载（保留 30 天）

## 怎么用

1. 改 `plans/<型号>.json`（镜头、字幕、封面）并推送 → 自动渲染这一款
2. 或者在 GitHub 网页 → Actions → “剪辑渲染” → Run workflow，填 `R18` / `R1-PRO,R18` / `all`
3. 运行结束后下载 Artifacts：`<型号>_30s_<版本>.mp4` + `<型号>_cover_<版本>.jpg`

## 文件结构

```
plans/            每款一份镜头表（R1-PRO.json、R18.json）
scripts/
  feishu_sync.cjs   从飞书读取表格、下载指定视频（访客身份，不需要账号）
  render.py         通用剪辑：按节拍切镜头、字幕、封面、片尾、配乐，只出网页版
  contact_sheets.py 每秒一帧的缩略图总览，挑镜头用
  fonts.py          字体查找
config/source.json  飞书表格地址、字段名、型号对照（FF352-2 = R1-PRO，507-1 = Movelck……）
assets/           背景音乐（Mixkit Daredevil，124 BPM）、白色 Logo
```

## 镜头表格式

```json
{
  "model": "R18", "version": "v1",
  "music": {"file": "assets/music/Mixkit_Daredevil.mp3", "start": 15.51, "bpm": 124},
  "cover": {"clip": "R18-1014-2-xi.mp4", "time": 18.6, "beats": 2, "kicker": "DUAL VISOR 3/4 HELMET", "title": "R18"},
  "texts": {"dot": ["MEETS DOT", "FMVSS 218"]},
  "segments": [{"clip": "R18-1014-2-xi.mp4", "start": 12.0, "beats": 7, "text": "dot", "speed": 1.0}],
  "endcard": {"title": "R18", "beats": 5}
}
```

- `clip`：飞书“文件名”转成的文件名，`西` → `xi`、`李` → `li`，例如 `R1pro-1014-5-西` → `R1pro-1014-5-xi.mp4`
- `beats`：镜头长度（拍）。124 BPM 时 1 拍 = 0.484 秒；封面 + 全部镜头 + 片尾 = **62 拍 ≈ 30 秒**
- `speed`：小于 1 是慢放（快速转动的镜头用 0.7）

## 剪辑规则（避坑记录，每次都要遵守）

| 问题（R1-PRO 第1版反馈） | 规则 |
|---|---|
| 炫彩头盔的镜头 1 秒就切走，太急 | 每个镜头不少于 3 拍（约 1.5 秒）；头盔快速转动的镜头放慢到 0.7 倍 |
| R18 推内墨镜片的动作没推完就切走了，关键操作没展示 | **关键操作必须完整展示**：推镜片、拨开关、拆内衬、扣卡扣等动作，镜头要从动作开始一直到动作完成（镜片完全推下、内衬完全取出）；只剪掉动作前后多余的部分。挑镜头时逐帧确认动作的起止秒数 |
| 字幕还没读完就消失 | 每组字幕至少 7 拍（约 3.4 秒），淡入 0.15 秒，出现后马上可读 |
| 标题太长超出画面 | 大字自动缩小，型号名做大字，说明文字做小字 |
| 封面是黑的、没有标题 | 开头不能从黑场淡入；视频前 2 拍就是封面（真人佩戴 + 小 Logo + 大标题），另出封面 JPG |
| 文案和官网不一致 | 字幕只写官网已审核的卖点：只写 DOT FMVSS 218，不写 ECE、专利、尾翼提高稳定性 |
| 画面不符合品牌调性 | 不用背景杂乱的镜头（仓库、一堆头盔）、开箱贴膜的镜头 |
| 小服务器渲染太慢（2 核 2GB 跑了 10 分钟以上） | 在 GitHub 云端渲染；每个镜头只编码一次，拼接和合音乐都不重新编码；只输出网页版 |

## 素材挑选

- 飞书表“素材总库”：审核状态为“通过”、播放量高的优先
- 先用 `contact_sheets.py` 生成每秒一帧的缩略图总览，再挑镜头写进镜头表
- 2026-10-19 统计：R1-PRO 37 条、R18 6 条、Movelck 2 条（素材太少，暂不剪）
